# SiteGround Migration & Deployment Checklist

This document outlines the steps to take the static Vanguard Realty Group site live on SiteGround, moving away from WordPress to a faster, more secure static hosting model.

## 1. Domain & DNS Preparation
The first step in the migration process involves connecting the existing domain to the new hosting environment. You will need to log into the domain registrar (such as GoDaddy or Namecheap) where `vanguardproperties.net` is currently registered. Next, log into the new SiteGround account and create a new website entry for the domain. Within the SiteGround Site Tools interface, locate the assigned Name Servers (NS) or the IP Address for the new server. Finally, update the domain's DNS records at the registrar to point to these new SiteGround credentials. Please note that DNS propagation can take anywhere from 1 to 24 hours to complete globally.

## 2. File Upload
Because the new website is built entirely with static HTML, CSS, and JavaScript—meaning it does not rely on PHP or a database—the upload process is remarkably straightforward. Navigate to the **Site > File Manager** section within SiteGround Site Tools. Open the `public_html` folder for `vanguardproperties.net` and delete any default placeholder files, such as `default.html`, that SiteGround may have placed there. Upload the entire contents of the `vanguard-mockup-v5` folder directly into `public_html`. It is critical to ensure that the primary `index.html` file sits directly inside the `public_html` directory, rather than being nested inside a subfolder, so the server can serve the homepage correctly.

## 3. Contact Form Setup (Formspree)
Since the new static architecture does not support traditional PHP-based form processing, the contact forms have been pre-wired to use **Formspree**, a reliable service designed specifically for handling form submissions on static websites. To activate this, visit [formspree.io](https://formspree.io/) and create a free account. Set up a new form project, which will generate a unique endpoint URL resembling `https://formspree.io/f/xbjvqwer`. Copy the unique 8-character ID at the end of that URL. Using the SiteGround File Manager text editor, open both `contact/index.html` and the main `index.html` (which houses the home valuation form). Locate the script tag at the bottom of each form and replace the placeholder `YOUR_FORM_ID` with your actual Formspree ID. Once saved, submit a test message through both forms on the live site to confirm that the inquiries are successfully routed to your email inbox.

## 4. Google Analytics Setup
An audit of the previous WordPress site revealed that Google Analytics was not installed. To ensure traffic is tracked accurately on the new platform, you will need to establish a new analytics property. Log into [analytics.google.com](https://analytics.google.com/) and create a new Google Analytics 4 (GA4) property dedicated to the website. The system will provide a Measurement ID, formatted similarly to `G-XXXXXXXXXX`. Return to the SiteGround File Manager and paste the provided GA4 tracking snippet into the `<head>` section of every `.html` file across the site to enable comprehensive traffic monitoring.

## 5. Final Verification
Once the files are uploaded and the DNS has propagated, perform a final quality assurance check. Confirm that the SSL certificate is active, as SiteGround typically provisions Let's Encrypt certificates automatically. Thoroughly test the navigation menu across both desktop and mobile devices to ensure responsiveness. Navigate to the Commercial pages to verify that the Crexi scraper is successfully populating the property listings, and click on the "View photos on Crexi" placeholders to ensure they link out to the correct external URLs. Finally, confirm that the IDX Broker widget loads properly within the designated section on the Residential page.
